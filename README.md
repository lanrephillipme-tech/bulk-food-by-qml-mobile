# Bulk Food by QML Mobile

Standalone Expo mobile app for Bulk Food by QML.

## Backend

The mobile app should call the live backend through:

```text
EXPO_PUBLIC_API_URL=https://bulk-food-by-qml.onrender.com
```

Copy `.env.example` to `.env` for local development if you need to change the backend URL.

## Development

```bash
npm install
npm run dev
```

## Builds

```bash
npm run build:android:apk
npm run build:android:aab
npm run build:ios
```
